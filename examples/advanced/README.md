# Advanced examples

Examples that go beyond a device-type reference firmware: they demonstrate SDK
extension points and integration patterns rather than "here is how a light
works". Start with a device example in [`examples/`](../) — [`light`](../light/)
is the usual entry point — and come here once you need to hook into the SDK
yourself.

| Example | Purpose |
| --- | --- |
| [`ota-custom`](ota-custom/) | Custom OTA filetype handler and custom (non-OTA) job callback |

These are **not** published to [ESP Launchpad](https://espressif.github.io/esp-launchpad/).
